# zkVM Verifier — автоматический верификатор инструкций RISC Zero

Инструмент для формальной проверки детерминированности инструкций виртуальной машины с нулевым разглашением (zkVM) RISC Zero. Верификатор анализирует исходные файлы спецификаций на языке Zirgen, автоматически извлекает арифметические ограничения, строит двухэкземплярную SMT-модель и проверяет её с помощью решателя CVC5.

## Возможности

- Лексический и синтаксический анализ языка Zirgen (поддержка компонентов, импортов, структурных типов, мажорных мультиплексоров, внешних объявлений)
- Понижение абстрактного синтаксического дерева (AST) в плоское промежуточное представление (IR)
- Генерация SMT-моделей в нескольких теориях / решателях:
  - **QF_BV** — битовые векторы (эффективно для побитовых операций)
  - **QF_NIA** — целочисленная нелинейная арифметика (поддержка UF-абстракции)
  - **QF_FF** — конечные поля через CVC5 + CoCoA (прямое моделирование арифметики BabyBear)
  - **msolve** — специализированный солвер полиномиальных систем (алгоритм F4 вычисления базисов Грёбнера)
- Модульная верификация через неинтерпретируемые функции (UF) для составных инструкций
- Прямая верификация над конечным полем без переформулировки и UF-абстракции (msolve)
- Точная семантика полевого деления BabyBear (без ложной недетерминированности)
- Автоматическая обработка кросс-файловых импортов

## Результаты

На реальных файлах спецификаций RISC Zero (`u32.zir`, `mult.zir`) автоматически верифицирована детерминированность всех базовых компонентов, включая арифметику, побитовые операции и умножение с накоплением.

С добавлением полевого бэкенда на основе msolve снята граница применимости общих SMT-теорий: умножение и деление верифицируются в их оригинальной лимбной форме напрямую, без переформулировки операндов и без UF-абстракции:

- `MultiplyAccumulate` (полный инлайн, 60 переменных, 16 байтовых произведений) — ~0,3 с;
- полная литеральная копия `DoDiv` из реального `inst_div.zir` (97 переменных, 89 ограничений) — ~1,4 с.

Теоретическое обоснование: целочисленная модель (QF_NIA/QF_BV) эквивалентна полевой при отсутствии переполнения поля (условие no-wrap), которое для оригинальных ограничений RISC Zero выполняется по построению; полевая семантика (QF_FF / msolve) необходима лишь там, где no-wrap нарушается.

## Требования

- Rust (последняя стабильная версия)
- CVC5 (установленный в системе)
- Скрипт-обёртка `cvc5-quiet` в корне проекта
- CVC5 со сборкой `--cocoa` — для бэкенда QF_FF (`verify-ff`)
- msolve (`brew install msolve`) — для бэкенда `verify-msolve`



## Использование

```bash
# сборка
cargo build --release

# верификация всех компонентов u32.zir (QF_BV)
cargo run --release -- verify specs/u32.zir all

# верификация mult.zir с UF-абстракцией (QF_NIA)
cargo run --release -- verify-int specs/mult.zir all --abstract=ExpandU32,SplitTotal

# верификация деления
cargo run --release -- verify-int specs/div.zir DoDivU

# верификация над конечным полем через CVC5 + CoCoA (QF_FF)
cargo run --release -- verify-ff specs/u32.zir NormalizeU32 --cvc5=/path/to/cvc5-cocoa

# прямая верификация полевым солвером msolve (включая полный DoDiv)
cargo run --release -- verify-msolve specs/u32.zir all
cargo run --release -- verify-msolve specs/mult.zir MultiplyAccumulate
cargo run --release -- verify-msolve specs/div_full.zir DoDiv

# просмотр промежуточного представления
cargo run --release -- ir specs/u32.zir AddU32
```

# zkVM Verifier — автоматический верификатор инструкций RISC Zero

Инструмент для формальной проверки детерминированности инструкций виртуальной машины с нулевым разглашением (zkVM) RISC Zero. Верификатор анализирует исходные файлы спецификаций на языке Zirgen, автоматически извлекает арифметические ограничения, строит двухэкземплярную SMT-модель и проверяет её с помощью решателя CVC5.

## Возможности

- Лексический и синтаксический анализ языка Zirgen (поддержка компонентов, импортов, структурных типов, мажорных мультиплексоров, внешних объявлений)
- Понижение абстрактного синтаксического дерева (AST) в плоское промежуточное представление (IR)
- Генерация SMT-моделей в двух теориях:
  - **QF_BV** — битовые векторы (эффективно для побитовых операций)
  - **QF_NIA** — целочисленная нелинейная арифметика (поддержка UF-абстракции)
- Модульная верификация через неинтерпретируемые функции (UF) для составных инструкций
- Точная семантика полевого деления BabyBear (без ложной недетерминированности)
- Автоматическая обработка кросс-файловых импортов

## Результаты

На реальных файлах спецификаций RISC Zero (`u32.zir`, `mult.zir`) автоматически верифицирована детерминированность 19 базовых компонентов, включая арифметику, побитовые операции, умножение с накоплением, а также собственную спецификацию беззнакового деления.

## Требования

- Rust (последняя стабильная версия)
- CVC5 (установленный в системе)  
- Скрипт-обёртка `cvc5-quiet` в корне проекта



## Использование

```bash
# сборка
cargo build --release

# верификация всех компонентов u32.zir (QF_BV)
cargo run --release -- verify specs/u32.zir all

# верификация mult.zir с UF-абстракцией (QF_NIA)
cargo run --release -- verify-int specs/mult.zir all --abstract=ExpandU32,SplitTotal

# верификация деления
cargo run --release -- verify-int specs/div.zir DoDivU

# просмотр промежуточного представления
cargo run --release -- ir specs/u32.zir AddU32
